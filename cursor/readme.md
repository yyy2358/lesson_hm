## @ 提及
- 在聊天输入框中键入 @，即可为你的提示附加特定上下文。在 @ 之后开始输入，Cursor 会显示匹配的建议项。
- 文件：使用 @auth.ts 来包含某个特定文件
- 文件夹：使用 @src/components/ 来包含整个文件夹 (选择后输入 / 可继续向下导航)
- 代码符号：使用 @getUserById 来引用某个具体的函数、类或变量
- 文档：使用 @Docs 来搜索已建立索引的文档，包括你自己的文档 (通过 @Docs > Add new doc 添加新文档)
历史对话：使用 @Past Chats 来引用之前会话中的上下文

# 搜索
- 代码不会存储在cursor的服务器中。Cursor 会创建向量嵌入，但不会存储文件名或源代码。文件名会被混淆处理，代码片段会被加密。当 Agent 搜索时，Cursor 会在客户端检索嵌入向量并解密这些片段。

## Explore 子代理
-  Explore 子代理 = 代码库的只读搜索引擎，帮你快速找东西、不写文件、不刷屏主对话。可以直接请求ai使用一个子代理 这样就不会生成大量上下文


# 并行代理
- 当 Cursor 创建一个 worktree 时，主工作树中的所有新文件和已编辑文件都会被带入该 worktree（唯一的例外是被 Git 忽略的文件）。
- 代理会在该 worktree 中隔离执行工作，并可能对文件进行修改。Best-of-N —— 同时使用多个模型
- 当你点击“应用”时，我们会尝试将这些更改干净地合并回你的主工作树。
- @parallel 启用并行代理

# AI模型
一篇文章让你吃透最好的AI编程工具cursor
模型被“训练”过的信息
你提供给模型的输入（“提示词”/prompt）
- 对模型返回的结果保持怀疑，并独立验证其建议是有必要的。
- 模型有时也会自信地给出错误答案。要有独立辩证的能力
- 令牌决定了模型的计费方式  令牌也是衡量模型速度的指标。
- 输入 token，包括你发送给模型的所有内容，例如提示词（prompt）和先前的对话。
- 输出 token，包括模型返回给你的所有生成内容。
- 需要有意识地控制初始上下文中包含的信息量   如何引导模型在回复中保持简洁或提供更详细的内容。    流式响应
- 清晰描述你想要实现的目标    
- 切换到其他任务时可以重新开启对话，而不是继续一个堆积无关历史的长串
- MCP 旨在成为将工具连接到 AI 模型的通用标准 。 AI 模型在不同应用间使用并集成各类工具
