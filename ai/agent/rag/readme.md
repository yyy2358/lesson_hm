## RAG 

- 向量化（Embedding）
    - 把用户问题、知识库文档，都用预训练的 Embedding 模型，转成高维向量（数字形式的语义表示）。

- Retriver 检索器
    - 原始的prompt embedding
    - 知识库 提前embedding 好的
    - cosine 相似度计算
    - 对用户问题的向量做相似度搜索，找到语义最相关的知识库片段。

- 知识库  要切分成文档碎片 节省开销   
    - 专家知识库
    - 企业私有/安全知识库
    - 各种类型的文件，txt pdf mp3 video
    - 大的文件切片 document 文档碎片
    - embedding化了5

- Augmented 增强
    - 原始的Prompt 增加 
    - 把检索到的文档，拼到用户的原始 Prompt 里，得到「增强后的 Prompt」。


- Generation 生成
    - llm 拿到增强的prompt 完美解答
    - 把增强后的 Prompt 喂给 LLM，生成有事实依据的回答。

## 向量表达？
向量表达，就是用预训练的 Embedding 模型(如OpenAI的text-embedding-ada模型)，把文本的语义信息，先转化成token 再压缩成一个高维数字数组（向量），让机器可以用 “向量距离” 来判断文本的语义相似度。
- 关键词的文本匹配不能实现语义搜索
    - 查询文中提到的水果，如何拿到苹果，香蕉，荔枝
    - 让机器能理解文本的 “意思”，而不只是字，同时实现高效、精准的语义检索
- 向量 Vector [0.1,0.2.....]
    用数字表达一个存储的信息

    - 食用性 0 无  1=高
    - 硬度 0 液体  1  骨头

- 向量化
    水果 [0.9,0.3] 食用性极高，硬度偏低
    苹果[0.9,0.5] 中等硬度
    香蕉[0.9,0.1] 很软
    石头[0.1,0.9] 硬度极高，食用性极低

- 语义搜索的流程
    - 向量每个维度有独特的语义（实用性、硬度）
    - 可视化  空间
    - cosine 计算
